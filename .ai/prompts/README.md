# .ai/prompts — AI Prompt Library

## Purpose

Thư mục lưu trữ tất cả AI prompts được tổ chức theo phase phát triển.
Mỗi Phase có thư mục riêng chứa prompt templates dùng cho coding agent (Antigravity/Gemini).

## Scope

6 phase phát triển, mỗi phase có thư mục riêng:

| Phase | Thư mục | Nội dung |
|-------|---------|----------|
| 1 | Phase01/ | Research & Environment Setup |
| 2 | Phase02/ | Data Collection & Model Training |
| 3 | Phase03/ | Backend API Development |
| 4 | Phase04/ | Frontend Development |
| 5 | Phase05/ | Integration & Testing |
| 6 | Phase06/ | Evaluation & Report |
