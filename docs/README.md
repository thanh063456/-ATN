# docs — Project Documentation

## Purpose

Thư mục lưu trữ tài liệu dự án dành cho con người: đề xuất đề tài, biên bản họp,
nhật ký thực nghiệm, báo cáo tốt nghiệp và tài liệu thuyết trình bảo vệ.

## Scope

5 tài liệu chính của quá trình làm đồ án tốt nghiệp:

| File | Mục đích |
|------|----------|
| Proposal.md | Đề xuất đề tài gửi GVHD |
| Meeting.md | Biên bản tất cả buổi họp |
| Experiment.md | Nhật ký thực nghiệm (CER/WER/latency logs) |
| Report.md | Outline và ghi chú báo cáo tốt nghiệp |
| Presentation.md | Kế hoạch và nội dung buổi bảo vệ |
